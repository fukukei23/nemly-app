# nemly 統計永続化 実装計画（L247・pass→purge 構造問題の解消）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** failCheck 判定統計（stationaryRate 等）と 10 秒窓生 amplitude を UI DB に永続化し、pass→purge しても校正データが失われないようにする（spec: `docs/superpowers/specs/2026-11-25-nemly統計永続化-design.md`・MLR r1+r2+r3 収束済み）。

**Architecture:** v4 マイグレーションで `sensor_verdicts` テーブルを新設し、既存の `amplitude_samples` テーブル（v2・書き込み経路なし）に生値を書く。書き込みは `saveImportArtifacts(verdict, samples)` 単一 API で単一トランザクション（2 値化）とし、import 経路の判定直後（insertSession 前）に呼ぶ順序契約（§3・kill 耐性）。verdicts は INSERT OR IGNORE（初回判定 immutable・r2 判断反転済み）。

**Tech Stack:** Expo/React Native（TypeScript）・expo-sqlite（async API・`withExclusiveTransactionAsync`）・jest（テスト）・schema_migrations フレームワーク（既存）。

**実装上の最重要注意（既存コードの罠）:**
- `failCheck.ts` の既存ローカル変数 `stationaryGateActive` は「**ゲート発動フラグ**」（windows 未指定時は初期値 `true` でゲート発動=判定ロジックの一部）。v4 の統計メタ「睡眠帯窓が存在したか」は**別変数 `sleepWindowGateActive` を新設**して返すこと。既存変数の初期値を変えると判定ロジックが壊れる（spec §10「判定ロジック 1 行も変更しない」違反になる）
- `quality` の契約は **0=OK（イベント数≥160）/ 1=DEGRADED（<160）**（`types.ts` SensorSample・`windowAggregator.ts:75` 実装と同一）
- `FailVerdict` は **判別ユニオン型**（3 バリアント）— spec §5 の interface 記述はユニオン拡張として実装する
- `sensorImport.ts` は既存から `@/lib/repository` を直接 import している（insertSession・getSessionByNativeId）— **saveImportArtifacts も repository 直呼びが既存パターンに合致**（SensorSeriesSource interface には足さない・nativeSource.ts は変更しない）

**Repository 読み取り API の追加理由:** テスト検証と朝回収 adb 照合（§9）のため、`getVerdictByNativeId` と `countAmplitudeSamples` も Repository interface に追加する（InMemory・SQLite 両実装に実装する）。

```ts
  private verdicts: Map<string, VerdictRecord> = new Map();
  private amplitudeRows: (AmplitudeSampleRow & { nativeSessionId: string })[] = [];

  async saveImportArtifacts(verdict: VerdictRecord, samples: AmplitudeSampleRow[]): Promise<void> {
    const existing = this.verdicts.get(verdict.nativeSessionId);
    if (existing) {
      // INSERT OR IGNORE: 初回のみ記録・上書きしない。値不一致なら警告（RM-2・judged_at は非決定なので除外比較）
      const { judgedAt: _ea, ...restE } = existing;
      const { judgedAt: _en, ...restN } = verdict;
      if (JSON.stringify(restE) !== JSON.stringify(restN)) {
        console.warn(
          `[v4] verdict mismatch on re-import: ${verdict.nativeSessionId}（既存行を保持・上書きしない）`
        );
      }
      return;
    }
    this.verdicts.set(verdict.nativeSessionId, { ...verdict });
    const seen = new Set(
      this.amplitudeRows
        .filter((r) => r.nativeSessionId === verdict.nativeSessionId)
        .map((r) => r.tsMs)
    );
    for (const s of samples) {
      if (!seen.has(s.tsMs)) {
        this.amplitudeRows.push({ nativeSessionId: verdict.nativeSessionId, ...s });
      }
    }
  }

  async getVerdictByNativeId(nativeSessionId: string): Promise<VerdictRecord | null> {
    const found = this.verdicts.get(nativeSessionId);
    return found ? { ...found } : null;
  }

  async countAmplitudeSamples(nativeSessionId: string): Promise<number> {
    return this.amplitudeRows.filter((r) => r.nativeSessionId === nativeSessionId).length;
  }
```

```ts
  async saveImportArtifacts(verdict: VerdictRecord, samples: AmplitudeSampleRow[]): Promise<void> {
    await this.db.withExclusiveTransactionAsync(async (tx: any) => {
      // verdicts: INSERT OR IGNORE（初回のみ記録・r2 判断反転）
      await tx.runAsync(
        `INSERT OR IGNORE INTO sensor_verdicts (
           native_session_id, started_at_ms, ended_at_ms, end_reason, verdict, reasons_json,
           stationary_rate, sleep_window_stationary_rate, stationary_gate_active,
           nan_rate, valid_ratio, expected_windows, actual_windows, judged_at
         ) VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)`,
        [
          verdict.nativeSessionId,
          verdict.startedAtMs,
          verdict.endedAtMs,
          verdict.endReason,
          verdict.verdict,
          JSON.stringify(verdict.reasons),
          verdict.stationaryRate,
          verdict.sleepWindowStationaryRate,
          verdict.stationaryGateActive ? 1 : 0,
          verdict.nanRate,
          verdict.validRatio,
          verdict.expectedWindows,
          verdict.actualWindows,
          verdict.judgedAt,
        ]
      );
      // 値不一致検知（RM-2: 既存行と比較・judged_at は非決定カラムなので除外・上書きはしない）
      const existing = await tx.getFirstAsync(
        `SELECT * FROM sensor_verdicts WHERE native_session_id = ?`,
        [verdict.nativeSessionId]
      );
      if (existing) {
        const prev = {
          verdict: existing.verdict,
          reasons: existing.reasons_json,
          stationaryRate: existing.stationary_rate,
          sleepWindowStationaryRate: existing.sleep_window_stationary_rate,
          stationaryGateActive: existing.stationary_gate_active,
          nanRate: existing.nan_rate,
          validRatio: existing.valid_ratio,
          expectedWindows: existing.expected_windows,
          actualWindows: existing.actual_windows,
        };
        const next = {
          verdict: verdict.verdict,
          reasons: JSON.stringify(verdict.reasons),
          stationaryRate: verdict.stationaryRate,
          sleepWindowStationaryRate: verdict.sleepWindowStationaryRate,
          stationaryGateActive: verdict.stationaryGateActive ? 1 : 0,
          nanRate: verdict.nanRate,
          validRatio: verdict.validRatio,
          expectedWindows: verdict.expectedWindows,
          actualWindows: verdict.actualWindows,
        };
        if (JSON.stringify(prev) !== JSON.stringify(next)) {
          console.warn(
            `[v4] verdict mismatch on re-import: ${verdict.nativeSessionId}（既存行を保持・上書きしない）`
          );
        }
      }
      // amplitudes: バッチ INSERT OR IGNORE（(session_id, ts_ms) UNIQUE・session_id=native_session_id 統一）
      for (const s of samples) {
        await tx.runAsync(
          `INSERT OR IGNORE INTO amplitude_samples (session_id, ts_ms, amplitude, quality) VALUES (?, ?, ?, ?)`,
          [verdict.nativeSessionId, s.tsMs, s.amplitude, s.quality]
        );
      }
    });
  }

  async getVerdictByNativeId(nativeSessionId: string): Promise<VerdictRecord | null> {
    const row = await this.db.getFirstAsync(
      `SELECT * FROM sensor_verdicts WHERE native_session_id = ?`,
      [nativeSessionId]
    );
    if (!row) return null;
    return {
      nativeSessionId: row.native_session_id,
      startedAtMs: row.started_at_ms,
      endedAtMs: row.ended_at_ms,
      endReason: row.end_reason,
      verdict: row.verdict,
      reasons: JSON.parse(row.reasons_json ?? "[]"),
      stationaryRate: row.stationary_rate,
      sleepWindowStationaryRate: row.sleep_window_stationary_rate,
      stationaryGateActive: row.stationary_gate_active === 1,
      nanRate: row.nan_rate,
      validRatio: row.valid_ratio,
      expectedWindows: row.expected_windows,
      actualWindows: row.actual_windows,
      judgedAt: row.judged_at,
    };
  }

  async countAmplitudeSamples(nativeSessionId: string): Promise<number> {
    const row = await this.db.getFirstAsync(
      `SELECT COUNT(*) AS n FROM amplitude_samples WHERE session_id = ?`,
      [nativeSessionId]
    );
    return row ? Number(row.n) : 0;
  }
```
