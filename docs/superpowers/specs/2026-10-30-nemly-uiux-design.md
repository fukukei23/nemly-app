# nemly-app UI/UX 仕上げ設計（案1「深夜パレット」）

> 📅 2026-10-30 · 承認: ふくけい（色見本画像 OK・2026-10-30 01:50）· 🔗 関連: [Phase2計測spec](../specs/2026-10-28_nemly-app-Phase2センサー計測-design.md)（実在する場合）

## 🎯 目標

Phase 1の最小構成画面（素のRN）を睡眠アプリとして仕上げる。**挙動は不変**（テスト161緑維持）で見た目と操作感だけを上げる。

## 🎨 テーマ定義（`src/constants/theme.ts` 新設・色を一元管理）

| トークン | 値 | 使いどころ |
|---|---|---|
| `colors.bg` | `#0F1420` | 画面全体の背景 |
| `colors.surface` | `#1A2233` | カード・ボタン面 |
| `colors.text` | `#E8ECF4` | 主テキスト |
| `colors.textSub` | `#8A94AC` | 副テキスト |

| `colors.phase.rem` | `#8B5FC7` | ヒプノグラムREM |

タイポ: `title 26bold / section 18bold / body 16 / sub 13`。スペーシング: `4/8/12/16/24`。角丸: カード12・チップ11。

テーマは `_layout.tsx` で **ダーク固定**適用（睡眠時間帯使用想定・ライト非対応=YAGNI）。

## 📱 画面構成（3画面）

1. **Home（index）**: タイトル+日付 → 計測カード（1タップ開始/停止・計測中はアクセント色ドット+経過時間）→ セッション一覧カード（日付・時間・スコアゴールド・ミニヒプノグラム）→ CSVインポート導線ボタン
2. **セッション詳細（session/[id]）**: スコア円形ゲージ（ゴールド・数字中心）+睡眠時間+時刻 → ヒプノグラム横バー（phase色分け）→ 統計チップ（深眠%/REM%/覚醒%）→ データ源バッジ（センサー/CSV）
3. **CSVインポート（import）**: 統一テーマ+大きな選択ボタン+3ステップ案内

## 🧩 実装方針

- 共通コンポーネントを `src/components/ui/` に新設: `ScoreGauge` / `HypnogramBar` / `SessionCard`
- ヒプノグラムは **Viewベースのバー描画**（外部ライブラリ不使用・YAGNI）
- 既存ロジック（repository・sleepAlgorithm・sensor）は**触らない**（見た目のみの変更）

## 🧪 テスト方針

- 既存テスト161緑の**維持が絶対条件**（挙動不変・壊れたらリバート）
- 新規: theme定義の一貫性テスト + 新コンポーネントのスナップショットテスト（既存jest構成準拠）
- 視覚確認: エミュレータ起動+スクショでCC自身が目視（実機はふくけい朝確認）

## ❌ 範囲外（YAGNI）

アニメーション多様・複数テーマ切替・アイコン一式（最小限のみ）・ライトテーマ。

## ⚠️ fail条件

デザイン適用で既存機能（スコア/ヒプノグラム表示・CSVインポート・SQLite契約10項目）が壊れた時 → **リバートで判定**（テスト161緑維持を前提）。
